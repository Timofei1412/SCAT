# 🛩️ Система оптимизации крыла с ML

Полная система для оптимизации геометрии крыла самолета с использованием машинного обучения, аэродинамического анализа и учетом ограничений по стабильности.

## 📋 Компоненты системы

### 1. **wing_optimizer.py** - Основной модуль оптимизации

Содержит функции для:

- Расчёта метрик стабильности (Cma, Clp, Cnr, и т.д.)
- Извлечения параметров геометрии крыла
- Оценки конфигураций с учётом:
  - Эффективности (CL/CD)
  - Минимальной площади крыла
  - Стабильности по крену и рысканью
  - Нейтральности по тангажу
- Генерации датасета конфигураций

**Ключевые классы:**

- `StabilityMetrics` - Метрики аэродинамической стабильности
- `WingMetrics` - Геометрические параметры крыла
- `DesignEvaluation` - Результат оценки конфигурации

### 2. **ml_wing_model.py** - ML модель и обучение

Нейросетевая модель для предсказания оптимальности конфигурации.

**Возможности:**

- Создание и обучение нейросети (TensorFlow/Keras)
- Анализ предсказаний модели
- Быстрая оценка кандидатов (вместо дорогих вычислений в AeroSandbox)
- Оптимизация с использованием обученной модели

**Архитектура:**

```
Input (параметры) → Normalization → Dense(256) → ReLU → Dropout
                  → Dense(512) → ReLU → Dropout
                  → Dense(256) → ReLU → Dropout
                  → Dense(128) → ReLU → Dropout
                  → Dense(1) → Output (скор)
```

### 3. **optimize_wing.py** - Интегрированная оптимизация

Главный скрипт, управляющий полной цепочкой:

1. Генерация датасета случайных конфигураций
2. Оценка каждой конфигурации в AeroSandbox
3. Обучение ML модели на датасете
4. Оптимизация с использованием модели

### 4. **analyze_wing.py** - Анализ результатов

Инструменты для анализа и визуализации:

- Статистика датасета
- Графики распределения параметров
- Поиск лучших конфигураций
- Анализ выполнения ограничений

## 🚀 Быстрый старт

### Этап 1: Генерация датасета

```bash
python3 -m SCAT.AERO.wing_optimizer \
    --samples 200 \
    --output wing_dataset.jsonl \
    --velocity 50.0 \
    --target-cl 0.55 \
    --min-wing-area 0.3
```

Это создаст датасет с 200 случайными конфигурациями крыла и оценит каждую в AeroSandbox.

**Выходные данные:**

- `wing_dataset.jsonl` - Датасет в JSONL формате

### Этап 2: Анализ датасета (опционально)

```bash
python3 -m SCAT.AERO.analyze_wing \
    --dataset wing_dataset.jsonl \
    --plot \
    --top-k 15
```

**Выходные данные:**

- `dataset_analysis.png` - Графики анализа датасета
- Статистика в консоли

### Этап 3: Обучение ML модели

```bash
python3 -m SCAT.AERO.ml_wing_model train \
    --dataset wing_dataset.jsonl \
    --output wing_model.keras \
    --epochs 100 \
    --batch-size 32
```

**Выходные данные:**

- `wing_model.keras` - Обученная модель

### Этап 4: Оптимизация

```bash
python3 -m SCAT.AERO.optimize_wing \
    --dataset wing_dataset.jsonl \
    --model wing_model.keras \
    --proposals 5000 \
    --evaluate-top-k 50 \
    --velocity 50.0 \
    --target-cl 0.55
```

Или использовать интегрированный скрипт (все этапы сразу):

```bash
python3 -m SCAT.AERO.optimize_wing \
    --samples 200 \
    --dataset wing_dataset.jsonl \
    --model wing_model.keras \
    --epochs 100
```

**Выходные данные:**

- `optimized_wing.json` - Оптимальная конфигурация в JSON
- `optimized_wing.py` - Python код для визуализации
- `optimized_params.json` - Параметры оптимизации
- Полный отчет в консоли

### Этап 5: Анализ модели (опционально)

```bash
python3 -m SCAT.AERO.ml_wing_model analyze \
    --model wing_model.keras \
    --dataset wing_dataset.jsonl
```

## 🎯 Ограничения и критерии оптимизации

### Ограничения (constraints):

1. **Площадь крыла** ≥ `min_wing_area` (по умолчанию 0.3)
2. **Демпфирование крена**: `Clp < -0.01` (отрицательное)
3. **Стабильность рысканья**: `Cnr > 0.01` (положительное)

### Критерии оптимизации:

1. **Эффективность**: `CL/CD` → max
2. **Близость к целевому CL**: штраф за отклонение от `target_cl`
3. **Нейтральность по питчингу**: `|Cm|` → min
4. **Стабильность по тангажу**: `Cma` должен быть отрицательным
5. **Демпфирование по тангажу**: `Cmq` должен быть отрицательным

## 🔧 Конфигурация параметров

Оптимизируемые параметры находятся в `optimizer.py`:


## 📈 Интерпретация результатов

### В датасете:

```
[✓] 0042/200 score= 3.756 eff= 12.45 area= 0.450 Clp=-0.25 Cnr= 0.12
[✗] 0043/200 score=-10.234 eff=  5.23 area= 0.250 Clp= 0.05 Cnr=-0.03
```

- `✓` = валидная конфигурация (все ограничения выполнены)
- `✗` = невалидная (нарушены ограничения)
- `score` = общий скор оптимизации
- `eff` = эффективность L/D
- `area` = площадь крыла
- `Clp` = демпфирование крена (должно быть < -0.01)
- `Cnr` = стабильность рысканья (должно быть > 0.01)

### При оптимизации:

```
[nn] rank=01/50 nn_pred= 3.856 real= 3.745 eff=12.34
```

- `rank` = ранг в топ-50 по предсказаниям нейросети
- `nn_pred` = предсказанный скор (быстро)
- `real` = реальный скор (точно, через AeroSandbox)
- `eff` = реальная эффективность

## 💡 Советы по использованию

1. **Начните с малого датасета** (50-100 примеров) для тестирования
2. **Используйте анализ** (`analyze_wing.py`) чтобы понять распределение данных
3. **Увеличивайте размер датасета** постепенно (200-500 примеров)
4. **Используйте `--only-valid`** при обучении, если нужны только реалистичные конфиги
5. **Настраивайте `--evaluate-top-k`** в зависимости от времени:
   - Быстро: 20-30
   - Тщательно: 50-100

## 🐛 Известные проблемы и решения

### Проблема: "TensorFlow не найден"

**Решение:**

```bash
pip install tensorflow
```

### Проблема: Долгая генерация датасета

**Решение:** Используйте параллельное выполнение или меньше примеров:

```bash
python3 -m SCAT.AERO.wing_optimizer --samples 100
```

### Проблема: Модель переучилась (overfitting)

**Решение:** Используйте меньше эпох или добавьте больше данных:

```bash
python3 -m SCAT.AERO.ml_wing_model train --dataset wing_dataset.jsonl --epochs 50
```

## 📚 Дополнительная информация

### Метрики стабильности в AeroSandbox:

- **Cma** (pitch stiffness) - производная Cm по α, должна быть отрицательной (восстанавливающий момент)
- **Cmq** (pitch damping) - производная Cm по угловой скорости тангажа
- **Clp** (roll damping) - производная Cl по угловой скорости крена, должна быть отрицательной
- **Clr** (roll/yaw coupling) - влияние рысканья на крен
- **Cnr** (yaw damping) - производная Cn по угловой скорости рысканья, должна быть положительной
- **Cnp** (yaw/roll coupling) - влияние крена на рысканье

### Рекомендуемые целевые значения:

- `target_cl` = 0.5-0.7 (для крейсерского полёта)
- `velocity` = 40-60 м/с (для малых БПЛА)
- `min_wing_area` = 0.25-0.5 м² (зависит от массы)
