# 📐 Ограничения на размах крыльев | Wing Span Limits

**Дата обновления:** 29 апреля 2026  
**Статус:** ✓ Активно

## 📋 Обзор

Система оптимизации крыла и базовая модель БПЛА настроены на жесткое соблюдение ограничения максимального размаха крыла **≤ 2.0 метра**.

## 🎯 Текущие параметры

### Базовая конфигурация (main.py)

| Поверхность         | Макс Y | Тип            | Размах | Статус          |
| ------------------- | ------ | -------------- | ------ | --------------- |
| **Основное крыло**  | 1.0 м  | Симметричное   | 2.0 м  | ✓ Соответствует |
| **Передние крылья** | 0.7 м  | Симметричные   | 1.4 м  | ✓ Соответствует |
| **Хвост (H)**       | 1.0 м  | Симметричный   | 2.0 м  | ✓ Соответствует |
| **Хвост (V)**       | 0.95 м | Несимметричный | 0.95 м | ✓ Соответствует |

### Ограничения при оптимизации (wing_optimizer.py)

#### Жесткое ограничение (Hard constraint)

```python
# Метод is_valid() - строка 115-116
if self.wing.span > 2.0:
    return False  # Конфигурация невалидна
```

- ✓ Применяется для всех режимов оптимизации
- ✓ Отклоняет конфигурации с размахом > 2.0 м

#### Мягкий штраф (Soft penalty)

```python
# Функция evaluate_wing_design() - строки 254-256
if wing_metrics.span > 2.0:
    constraints_violation += (wing_metrics.span - 2.0) * 5.0
```

- ✓ Штраф: 5.0 за каждый метр превышения
- ✓ Используется при расчете скора оптимизации
- ✓ Позволяет ML-модели обучаться на пограничных случаях

## 🤖 ИИ модель

### Обучение датасета (ml_wing_model.py)

- ✓ Все примеры в датасете проходят проверку `is_valid()`
- ✓ Размах всех крыльев в датасете ≤ 2.0 м
- ✓ NN обучается на валидных конфигурациях

### Оптимизация (optimize_with_neural_network)

```python
evaluation = wing_opt.evaluate_wing_design(
    config,
    velocity=velocity,
    target_cl=target_cl,
    min_wing_area=min_wing_area,
)
if evaluation.is_valid(min_wing_area):  # ← Проверка размаха
    # Конфигурация допускается
```

- ✓ Размах проверяется при детальной оценке топ-50 кандидатов
- ✓ Только валидные конфигурации рассматриваются для улучшения

## ⚠️ Проверка соответствия

Для быстрой проверки размаха текущей конфигурации:

```python
from SCAT.AERO import main, optimizer

config = main.default_config()
span = optimizer.surface_half_span(config.wing) * 2.0  # для симметричного крыла
print(f"Размах основного крыла: {span:.2f} м")

# Проверка валидности
from SCAT.AERO import wing_optimizer as wing_opt
eval_result = wing_opt.evaluate_wing_design(config)
is_valid = eval_result.is_valid()
print(f"Конфиг валиден (размах ≤ 2.0м): {is_valid}")
```

---

## 📌 Важные замечания

1. **Размах рассчитывается как:** `max(y) - min(y)` для каждой крыловой поверхности
2. **Для симметричных крыльев:** размах = `(max_y - min_y) * 2`
3. **Ограничение 2.0 м** применяется только к основному крылу (wing)
4. **Передние крылья (canard)** могут быть меньше, но их размах косвенно влияет на скор через соотношение площадей
