# 🚀 Интегрированная система оптимизации крыла в веб-интерфейс

## Что было добавлено

Веб-интерфейс теперь поддерживает **три режима оптимизации** крыла:

### 1. 🧬 Алгоритм (CEM) - `algorithm`

**Описание:** Чистая генетическая оптимизация через кросс-энтропийный метод.

**Преимущества:**

- ✅ Работает без предварительно обученной модели
- ✅ Надежный и проверенный метод
- ✅ Универсален для любых конфигураций

**Недостатки:**

- ⏱️ Медленнее, чем AI (требует много вычислений)
- Требует больше итераций для хорошего результата

**Когда использовать:**

- Первый запуск (нет ML модели)
- Нужна надежность выше скорости
- Исследование новых архитектур

---

### 2. 🤖 AI (Нейросеть) - `ai`

**Описание:** Оптимизация через обученную нейросеть (требует `wing_model.keras`).

**Преимущества:**

- ⚡ **Очень быстро** (тысячи кандидатов за секунды)
- 📊 Хороший результат, если модель хорошо обучена
- Низкие требования к вычислительным ресурсам

**Недостатки:**

- ❌ Требует предварительно обученную модель
- Может выйти за границы обучающего датасета
- Качество зависит от качества обучения

**Когда использовать:**

- У вас уже есть обученная модель
- Нужна **максимальная скорость**
- Вы уверены в качестве модели

**Подготовка модели:**

```bash
# 1. Сгенерировать датасет
python3 -m SCAT.AERO.wing_optimizer --samples 200 --output wing_dataset.jsonl

# 2. Обучить модель
python3 -m SCAT.AERO.ml_wing_model train --dataset wing_dataset.jsonl --epochs 100
```

---

### 3. 🔄 Гибридный (AI+CEM) - `ai+algorithm`

**Описание:** Комбинированный подход - AI для быстрого поиска + CEM для уточнения.

**Преимущества:**

- 🎯 **Лучший результат** (комбинирует оба метода)
- ⚡ Быстрее, чем CEM один
- 🔍 Более тщательный поиск благодаря локальному уточнению

**Недостатки:**

- Требует обученную модель AI
- Немного дороже вычислительно, чем просто AI

**Как работает:**

1. **Этап 1 (AI):** Быстро оценить тысячи кандидатов нейросетью
2. **Этап 2 (CEM):** Взять топ кандидатов и уточнить через генетику
3. **Результат:** Лучший из обоих миров

**Когда использовать:**

- Нужен **максимальный результат**
- У вас есть обученная модель
- Приемлемое время оптимизации

## 🎨 Веб-интерфейс - панель оптимизации

На правой панели появились новые опции:

```
┌─────────────────────────────────────┐
│ Параметры оптимизации               │
├─────────────────────────────────────┤
│                                     │
│ Режим оптимизации *                 │
│ [🧬 Алгоритм       ▼]              │
│ [🤖 AI             ]               │
│ [🔄 Гибридный      ]               │
│                                     │
│ Итерации:           [10]            │
│ Популяция:          [20]            │
│ Мин. площадь крыла: [0.3]           │
│ Целевой CL:         [0.55]          │
│ Скорость, м/с:      [50]            │
│                                     │
└─────────────────────────────────────┘
```

### Параметры:

| Параметр         | Описание                         | Рекомендация            |
| ---------------- | -------------------------------- | ----------------------- |
| **Режим**        | Выбрать метод оптимизации        | Начните с Алгоритма     |
| **Итерации**     | Количество итераций поиска       | AI: 1-5, CEM: 5-15      |
| **Популяция**    | Размер популяции на итерацию     | 15-30 (больше = точнее) |
| **Мин. площадь** | Минимум площади крыла для полета | ~0.3-0.5 м²             |
| **Целевой CL**   | Коэффициент подъема для крейсера | 0.5-0.7                 |
| **Скорость**     | Скорость полета для анализа      | 40-60 м/с               |

## 📋 Критерии оптимизации

Система оптимизирует **следующие параметры:**

### ✅ Максимизация:

- **Efficiency (CL/CD)** - главный критерий
- **Площадь крыла** ≥ Мин. (необходимо для полета)

### ✅ Стабильность:

- **Клп (roll damping)** < -0.01 (демпфирование крена)
- **Cnr (yaw stability)** > 0.01 (стабильность рысканья)
- **Cm (pitch moment)** ≈ 0 (нейтральность по тангажу)

### ⚠️ Штрафы:

- Отклонение от целевого CL
- Неустойчивость по крену/рысканью
- Нарушение минимальной площади
- Геометрические аномалии

## 🔌 Технические детали интеграции

### Backend (main.py)

Обновлен HTTP endpoint `/api/optimize`:

```python
if parsed.path == "/api/optimize":
    import SCAT.AERO.wing_optimization_v2 as opt_engine

    engine = opt_engine.WingOptimizationEngine(config)
    result = engine.optimize(
        mode=options.get("mode", "algorithm"),
        iterations=iterations,
        population=population,
        velocity=velocity,
        target_cl=target_cl,
        min_wing_area=min_wing_area,
    )
    self._send_json(result)
```

### Frontend (JavaScript)

1. **Выбор режима** через dropdown в панели параметров
2. **Отправка запроса** с выбранным режимом
3. **Обработка результатов** в универсальном формате
4. **Отображение** на canvas (оранжевая пунктирная геометрия)

## 💡 Советы по оптимизации

### Для быстрого прототипирования:

- Режим: **AI** (если есть модель)
- Итерации: 1-3
- Популяция: 10-15

### Для серьезной оптимизации:

- Режим: **Гибридный** или **Алгоритм**
- Итерации: 10-20
- Популяция: 25-50

### Если результат плохой:

1. Увеличьте итерации и популяцию
2. Измените параметры (целевой CL, минимум площади)
3. Переобучите ML модель (если используете AI)

### Если оптимизация долгая:

1. Используйте **AI режим** (намного быстрее)
2. Уменьшите итерации/популяцию
3. Оптимизируйте на более быстром компьютере

## ❓ Часто задаваемые вопросы

**Q: Какой режим выбрать?**
A: Начните с "Алгоритм" (всегда работает), потом попробуйте AI если есть модель.

**Q: Почему AI результат хуже?**
A: Модель может быть плохо обучена. Переобучите ее на более большом датасете.

**Q: Как долго оптимизация?**
A: AI - секунды, Гибридный - минуты, Алгоритм - 5-30 минут в зависимости от параметров.

**Q: Могу ли я остановить оптимизацию?**
A: Нет, но вы можете уменьшить итерации/популяцию перед запуском.

**Q: Какие еще параметры можно оптимизировать?**
A: На данный момент оптимизируется только крыло. Расширение скоро.
